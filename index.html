Reck Profile Backup

Reck Profile Backup is a privately operated Python utility that protects the owner's selected Windows files and project folders. It runs on the owner's computer, creates encrypted archives and can copy those archives to a connected USB drive, Microsoft OneDrive and Google Drive.

This website documents the application. It does not run backups, collect credentials or provide a public sign-up service. Google authorization happens through Google's sign-in page and the local backup program.

What the application does

  • Copies new and updated selected files into a local working folder, then compresses the saved set into WinZip AE-2 AES-256 encrypted ZIP archives.
  • Verifies the encrypted archive contents locally and checks cloud uploads by downloading the stored bytes through SHA-256 verification.
  • Supports daily local and connected-USB backups, plus weekly cloud copies with a configurable history of one to four cloud sets.
  • Removes surplus owned cloud backup sets only after verifying the replacement, and reports failures or unreadable source files.

These are file backups, not complete Windows system images. Excluded folders, links and certain live, temporary or cached files are not included. The local working copy is unencrypted, and encrypted ZIP filenames remain visible.

Why Google Drive access is requested

drive.file lets the app create and manage the backup files it creates or that the user authorizes it to access. drive.metadata.readonly lets it inspect file and folder metadata, identify its dedicated backup folder, check available storage and detect unexpected contents before cleanup. Metadata access can include information about other files in the connected Drive account; it does not itself authorize reading their contents.

The program uses a dedicated, ownership-marked cloud backup folder. It does not intentionally modify unrelated Google Drive files or empty the account's whole trash.
